# Kadr

Захват страницы, редактор-«украшатель» и запись инструкции из кликов — для браузеров
на Chromium.
Все функции редактора бесплатны и работают офлайн: без триала, вотермарок и PRO-замка.

> English: [README.md](README.md)

**Статус: фазы 0–6.5 готовы, идёт подача v1.0 в Chrome Web Store. Захват, редактор,
рамки и мокапы, ИИ-слой с офлайн-замазкой, библиотека снимков, пресеты стилей, трекеры
задач, Scribe-инструкции, пересъёмка по рецепту и выгрузка таблиц — на месте.
Запись экрана выйдет следующим релизом (фаза 7).**

## Что это

|             |                                                                                                                                                                                                                 |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Захват      | Вся страница, видимая область, выделение мышью, элемент DOM и съёмка со скроллом: чат или виртуализованная лента склеиваются по содержимому, а не по координате. Внутренние скролл-контейнеры, responsive-серия |
| Редактор    | Один Konva-документ рендерит и превью, и экспорт — в файле ровно то, что на экране. Undo/redo работает на всём документе, а не только в панели рисования                                                        |
| Аннотации   | Нумерованные бейджи-шаги, семь стилей стрелок, spotlight, хайлайт и блюр, который остаётся перемещаемым слоем, а не выжигается в пиксели                                                                        |
| Приватность | Нет телеметрии и нет бэкенда. Скриншоты не покидают устройство, пока вы явно не запустите действие ИИ своим ключом                                                                                              |
| ИИ          | BYOK: Anthropic, OpenAI, Google или любой OpenAI-совместимый эндпоинт, включая локальные Ollama и LM Studio. Замазка PII работает и офлайн — на локальном OCR, без ключа                                        |

## Установка из исходников

```bash
npm install
npm run build
```

Дальше `chrome://extensions` → включить **Режим разработчика** → **Загрузить распакованное
расширение** → выбрать папку `dist/`.

Для разработки с горячей перезагрузкой:

```bash
npm run dev
```

Папка `dist/` загружается так же, Vite пересобирает и перезагружает расширение по сохранению.

## Разрешения

Базовая установка просит `activeTab`, `scripting`, `storage`, `unlimitedStorage`,
`downloads`, `offscreen` и `contextMenus` — никаких host-разрешений. `activeTab` выдаётся
при клике по иконке, пункте контекстного меню и по горячей клавише, а это ровно все точки
входа в захват.

Всё тяжёлое — опциональное и запрашивается при включении соответствующей функции:
`tabCapture` и `desktopCapture` для записи, `tabs` для пакетного захвата вкладок, доступ
к хосту трекера — в момент нажатия «Отправить».

## Релиз

Тег `v*` запускает релизный workflow: он сверяет тег с `package.json`, собирает пакет и
прикладывает к релизу на GitHub и его, и архив исходников. Один и тот же пакет уезжает
в Chrome Web Store, Opera Add-ons и Edge Add-ons — тексты листинга и чек-лист подачи лежат
в [store/](store), политика приватности — в [docs/](docs).
