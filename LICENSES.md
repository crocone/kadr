# Third-party licenses

The repository is public, so every asset has to be traceable to a licence we can
actually point at. Backgrounds are generated in code, device mockups are drawn by
hand as SVG, and fonts are OFL only. Nothing here is lifted from another product.

## Bundled assets

| Asset                | Origin                                            | Licence               |
| -------------------- | ------------------------------------------------- | --------------------- |
| `assets/icons/*.png` | Generated by `scripts/gen-icons.mjs`              | MIT (this repository) |
| Gradient presets     | Generated in code, `src/core/doc/backgrounds.ts`  | MIT (this repository) |
| Wallpaper patterns   | Generated in code, `src/core/render/wallpaper.ts` | MIT (this repository) |

Fonts, device mockups and wallpapers land here as they are added. The rule for a new
asset: either we drew it, or it ships under OFL / CC0 / MIT with the source recorded
in this table.
