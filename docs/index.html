Kadr

Page capture and a screenshot beautifier for Chromium browsers. Every editor feature is free and works offline: no trial, no watermark, no PRO lock.

What it does

  • Full page, visible area, a dragged region or a DOM element — and a responsive series in three widths.
  • One document renders both the preview and the export, so the file matches the screen.
  • Arrows, step badges, spotlight, and blur that stays a movable layer instead of burnt pixels.
  • A library of shots with search by site, tag and recognised text.
  • Two clicks from a shot to a GitHub, Linear or Jira issue.
  • Offline PII redaction: text recognition runs in the browser, with no key and no server.

Privacy

No telemetry, no backend, no account. Screenshots stay on the device unless you press something that says it will send them — read the privacy policy for the exact list.

Get it

  • Source code on GitHub — MIT.
  • Releases — the same package that goes to the stores.

Kadr

Захват страницы и оформление скриншотов для Chromium-браузеров. Все возможности редактора бесплатны и работают офлайн: без триала, вотермарок и PRO-замка.

Что умеет

  • Вся страница, видимая область, выделенный участок или элемент — и responsive-серия в трёх ширинах.
  • Один документ рисует и превью, и экспорт, поэтому файл совпадает с тем, что на экране.
  • Стрелки, нумерованные шаги, spotlight и блюр, который остаётся слоем, а не выжженными пикселями.
  • Библиотека снимков с поиском по сайту, тегам и распознанному тексту.
  • Два клика от кадра до задачи в GitHub, Linear или Jira.
  • Замазка приватных данных офлайн: распознавание идёт в браузере, без ключа и без сервера.

Приватность

Ни телеметрии, ни сервера, ни аккаунта. Скриншоты не покидают устройство, пока вы не нажмёте то, что прямо говорит об отправке, — точный список в политике приватности.
