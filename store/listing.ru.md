# Листинг Chrome Web Store — русский

## Название

Kadr — скриншоты и инструкции

## Короткое описание (до 132 символов)

Снимок любой страницы, оформление кадра и замазка приватного офлайн. Без триала, вотермарок
и PRO-замка.

## Категория

Работа и планирование

## Одна заявленная цель

Захват и оформление скриншотов веб-страниц. Всё в расширении служит этой цели: режимы
захвата дают кадр, редактор его оформляет, библиотека хранит, интеграция с трекером
доставляет, а запись инструкции превращает проход по интерфейсу в нумерованные шаги.

## Полное описание

**Снять.** Вся страница, сшитая из кадров, видимая область, выделенный мышью участок с
пиксельной лупой или элемент страницы, выбранный наведением. Responsive-серия снимает 375,
768 и 1440 px подряд и кладёт все три кадра на один холст.

**Оформить.** Фоны, нарисованные кодом, — градиенты, узоры, заливки, — отступы,
скругление, тени, настоящие рамки macOS и Windows 11 с редактируемым адресом, корпуса
устройств и свой мокап. Весь вид сохраняется пресетом стиля, а JSON пресетов можно передать
команде.

**Объяснить.** Стрелки семи стилей, нумерованные бейджи шагов, spotlight, маркер, текст
локальными шрифтами, фигуры и выноски. Блюр остаётся слоем, который можно подвинуть или
снять, а не выжженными в картинке пикселями.

**Спрятать лишнее.** Распознавание текста идёт внутри браузера — без ключа, без сервера и
без загрузки кадра — и находит почту, телефоны, карты и токены, чтобы закрыть их одним
нажатием. Ничего не замазывается без подтверждения, и ничто не считается гарантией:
проверьте кадр перед публикацией.

**Отправить туда, где работа.** Библиотека с поиском по сайту, дате, тегам и тексту,
распознанному на снимке. Копирование картинкой, markdown или data-URI. Экспорт PNG, JPEG,
WebP и PDF. Или сразу задача в GitHub, Linear или Jira по своему токену — вместе с
картинкой уедут адрес страницы, браузер и размер экрана.

**ИИ — свой ключ или никакого.** ИИ выключен по умолчанию и не делает ни одного запроса,
пока его не включат и не введут ключ. Подходит любой OpenAI-совместимый эндпоинт, включая
локальные Ollama и LM Studio, а замазке выше ИИ не нужен вовсе.

**Ноль телеметрии.** Ни строки о пользователе никуда не уходит: ни счётчиков, ни аналитики,
ни «анонимной статистики». Сетевых запросов ровно три вида, и все — по вашему нажатию:
действие ИИ по вашему ключу, разовая загрузка словаря для офлайн-распознавания и отправка
снимка в настроенный вами трекер.

Открытый код, MIT: <https://github.com/crocone/kadr>

## Честные ограничения

- Chrome ограничивает съёмку вкладки примерно двумя кадрами в секунду, поэтому длинная
  страница снимается заметно медленно.
- Страницы браузера, Web Store и других расширений снять нельзя — это правило платформы, а
  не ошибка.
- Виртуализованные списки (react-window и подобные) ломают сшивку: в DOM физически нет
  строк, которые сейчас за экраном.
- Responsive-серия действительно меняет размер окна, и это видно, пока она идёт.

## Обоснование разрешений

| Разрешение                     | Зачем                                                                                                                                                                                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `activeTab`                    | Прочитать снимаемую страницу в момент, когда захват запущен иконкой, меню или горячей клавишей                                                                                                                                                                           |
| `scripting`                    | Вставить в эту вкладку оверлей выделения и скрипт измерения страницы                                                                                                                                                                                                     |
| `storage`, `unlimitedStorage`  | Хранить документы, кадры и настройки локально; скриншоты весят много, и их много                                                                                                                                                                                         |
| `downloads`                    | Сохранить файл экспорта                                                                                                                                                                                                                                                  |
| `clipboardWrite`               | Скопировать кадр в буфер по кнопке «Копировать»                                                                                                                                                                                                                          |
| `contextMenus`                 | Пункты контекстного меню, ведущие в захват                                                                                                                                                                                                                               |
| `offscreen`                    | Рендер и кодирование вне service worker, у которого нет DOM                                                                                                                                                                                                              |
| Доступ к хостам (`<all_urls>`) | Опционально, по одному сайту и всегда по кнопке: пересъёмка сохранённого кадра, запись инструкции с переходами между страницами и отправка в настроенный трекер; Linear дополнительно требует storage.googleapis.com — туда его API отдаёт presigned-ссылку для вложения |
| `wasm-unsafe-eval` в CSP       | Офлайн-распознавание собирает WebAssembly-модуль, лежащий в самом пакете; `eval()` и строки-как-код остаются запрещёнными                                                                                                                                                |
